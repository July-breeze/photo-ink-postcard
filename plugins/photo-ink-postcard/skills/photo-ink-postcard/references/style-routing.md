# 参考图路由

参考资产分为两个互不替代的层级：一张固定的材质基准，以及每次只选择一张的构图基准。不要把全部构图图同时提交给生成模型。

## 图像角色

- Image 1：用户照片。唯一的内容、空间关系和配色来源。
- Image 2：`assets/style-material-reference.png`。只提供纸张、淡矿物色、水墨渗化、干湿笔触与柔化边缘；不得提供景物或布局。
- Image 3：从下表选择的单张构图基准。只提供虚实比例、主体落点、方向与消隐节奏；不得提供题材、地貌身份或颜色。

如果工具只能接收两张参考图，优先保留 Image 1 与选中的构图基准，并把材质要求完整写入提示词。不要因此加入第二张构图基准。

## 选择规则

| 原图的主要叙事结构 | 选择的构图基准 | 主要借鉴内容 |
| --- | --- | --- |
| 一位或少数明确主体人物与自然景观共同构成叙事，人物不是偶然游客 | `assets/composition-human-landscape.png` | 人为“点”、山水与留白为“面”的尺度关系，人物朝向与呼吸路径 |
| 一只或少数明确主体动物与环境形成动作叙事 | `assets/composition-small-focal-point.png` | 生命主体的偏置落点、小焦点与大留白；动物本身按“动物主体减法”处理，不复制参考图物体 |
| 湖、河、海、湿地、低地平线或大面积水平水面 | `assets/composition-horizontal-water.png` | 低位横势、断续岸线、上方大留白 |
| 单一山峰、山脊、峡谷或明显的斜向上升走势 | `assets/composition-mountain-diagonal.png` | 对角动势、单侧聚墨、向空白处消隐 |
| 亭、屋、塔、舟或其他必须保留的小尺度视觉锚点 | `assets/composition-small-focal-point.png` | 小焦点与大留白的尺度关系、偏置落点 |
| 林海、雾林、丘陵或多层植被，没有必须突出的单峰 | `assets/composition-layered-forest.png` | 前深后淡的层叠节奏、轮廓递次消失 |

## 冲突时的优先级

1. 若存在明确的叙事主体人物，优先选择“人物点景”；自然地貌仍从 Image 1 提取，不再叠加第二张山水构图参考。
2. 否则若存在明确主体动物，或小型建筑、船、器物或暖色物体是照片不可替代的视觉锚点，选择“小焦点”。动物的数量、姿态与方向来自 Image 1，不从构图参考借用任何生物形态。
3. 否则若存在明确山峰或强斜线，选择“山体斜势”。
4. 否则若水平水面主导画面，选择“水岸横势”。
5. 其余多层森林、雾景与丘陵选择“层叠林雾”。

选择后，在提示词中写明文件名和选择原因，例如：`Image 3 is the routed composition reference because the source is dominated by a low water horizon.` 不得复制参考图里的山形、岸线、树丛、亭子或其他虚构景物。

## 稳定性检查

- 每次固定使用同一张材质基准，只更换一张构图基准。
- 不使用两张以上构图基准，不做平均混合。
- 若结果像参考图而不像用户照片，强化 Image 1 的内容唯一性并降低构图参考权重。
- 若结果笔触稳定但章法不对，只更换构图基准，不更换材质基准。
- 若章法正确但边缘生硬、纸色偏黄或纹理过密，只修改材质描述，不更换构图基准。
- 人物点景结果若像人物海报，缩小人物并扩大其朝向一侧的留白；若人物不可辨识，增强一个服装色块或轮廓姿态，而不是补画五官。
- 动物结果若像写实水彩或自然图鉴，不仅要降低细节，还要把动物身体压缩为 5–9 个墨形、把环境缩为 2–3 个大形体，并将纸面提高到 62–75%；若动物不可辨识，只恢复耳形、背弧、尾势或最多 2–3 个物种记号，不恢复眼睛、毛发或完整解剖。
